### 1. 什么是逼近模式？

逼近模式用于让机器人在运动到目标点之前就开始减速并转向下一个点，从而实现**平滑过渡**，避免机器人频繁启停。这样可以：

- 提高节拍时间（效率）
    
- 减少机械冲击
    
- 使运动轨迹更平滑
    

**核心逻辑：** 机器人不会精确停靠在每个目标点，而是在距离目标点一定“条件”时就开始转向下一条运动指令。

---

### 2. 核心系统变量

所有逼近阈值都通过 `$APO` 系统变量设置：

|系统变量|单位|含义|适用模式|
|---|---|---|---|
|`$APO.CPTP`|%|关节剩余角度百分比阈值|`C_PTP`|
|`$APO.CDIS`|mm|TCP到目标点的距离阈值|`C_DIS`|
|`$APO.CORI`|°（度）|工具姿态角度差阈值|`C_ORI`|
|`$APO.CVEL`|%|当前速度/编程速度百分比阈值|`C_VEL`|

**设置示例：**

krl

$APO.CPTP = 80   ; PTP逼近：各关节剩余角度小于最大角度差的80%时触发
$APO.CDIS = 10.0 ; 距离逼近：TCP距目标点小于10mm时触发
$APO.CORI = 5.0  ; 姿态逼近：姿态角度差小于5°时触发
$APO.CVEL = 30   ; 速度逼近：当前速度降至编程速度的30%时触发

---

### 3. 四种核心逼近模式

|逼近模式|全称|触发条件|适用运动类型|核心变量|
|---|---|---|---|---|
|`C_PTP`|C_PTP (Point-To-Point)|各关节剩余角度 < `$APO.CPTP`|**PTP → PTP**|`$APO.CPTP`|
|`C_DIS`|C_Distance|TCP到目标点距离 < `$APO.CDIS`|**LIN / CIRC**|`$APO.CDIS`|
|`C_ORI`|C_Orientation|工具姿态角度差 < `$APO.CORI`|**LIN / CIRC**|`$APO.CORI`|
|`C_VEL`|C_Velocity|当前速度 < 编程速度 × `$APO.CVEL`%|**LIN / CIRC**|`$APO.CVEL`|

#### 3.1 `C_PTP` — 关节空间逼近

**原理：** 监控机器人各关节的剩余角度（相对于目标姿态的角度差）。当所有关节的剩余角度都小于最大角度差的某一百分比时触发逼近。

**注意：** `$APO.CPTP` 的100%表示**两个PTP点之间总角度差的一半**。这是系统内部的归一化方式。

**适用场景：** PTP运动之间的平滑衔接，追求各轴运动效率。

---

#### 3.2 `C_DIS` — 距离逼近

**原理：** 监控TCP（工具中心点）在空间中的位置。当TCP距离目标点的直线距离小于设定的毫米数时触发逼近。

**适用场景：** 对路径精度要求较高的场合，希望在指定位置附近开始拐弯。

---

#### 3.3 `C_ORI` — 姿态逼近

**原理：** 监控工具姿态（ABC欧拉角）。当当前姿态与目标姿态的角度差小于设定的阈值时触发逼近。

**适用场景：** 姿态变化较大的连续路径运动（如焊接、涂胶时工具需要大幅调整角度）。

---

#### 3.4 `C_VEL` — 速度逼近

**原理：** 监控当前运动速度。当速度降至编程速度的某一百分比时触发逼近。

**适用场景：** 追求极致节拍，对路径精度要求不高的场合（如粗加工、搬运）。尤其适用于密集路径点，可避免频繁启停导致的抖动。

---

### 4. 如何在运动指令中使用

在运动指令末尾直接添加对应的 `C_` 关键字：

krl

; PTP运动
PTP P1 C_PTP              ; PTP → PTP 使用关节逼近
; PTP → CP (LIN/CIRC) 运动
PTP P1 C_PTP C_DIS        ; 必须同时指定C_PTP和一个CP逼近模式
; CP运动 (LIN / CIRC)
LIN P1 C_DIS              ; 距离逼近
LIN P1 C_ORI              ; 姿态逼近
LIN P1 C_VEL              ; 速度逼近
CIRC P1 P2 C_DIS C_ORI    ; 圆弧运动组合逼近

---

### 5. 组合使用（多重逼近）

一条运动指令可以同时指定多个逼近模式，系统会**同时监控**所有条件：

#### 5.1 允许的组合方式

|运动类型|允许的组合|
|---|---|
|**PTP → PTP**|`C_PTP`|
|**PTP → CP**|`C_PTP C_DIS` / `C_PTP C_ORI` / `C_PTP C_VEL`|
|**CP → CP**|`C_DIS` / `C_ORI` / `C_VEL` / `C_DIS C_ORI` / `C_DIS C_VEL` / `C_ORI C_VEL` / `C_DIS C_ORI C_VEL`|

#### 5.2 组合后的逻辑：**先到先得**

当组合使用时，系统监控所有条件，**任何一个条件先满足即触发逼近**。

krl

; 同时监控距离和速度，谁先满足谁触发
LIN P2 C_DIS C_VEL

**注意：** 语法上不强制先后顺序，`LIN P2 C_VEL C_DIS` 同样有效。

**推荐书写顺序：** `C_DIS` → `C_ORI` → `C_VEL`（由具体到抽象，便于阅读）。

---

### 6. 特殊组合模式 `C_AP`

`C_AP`（C_Approximation）是一个**组合指令**，相当于 `C_DIS C_ORI` 的简写：

krl

LIN P2 C_AP            ; 等价于 LIN P2 C_DIS C_ORI
LIN P2 C_AP C_VEL      ; 等价于 LIN P2 C_DIS C_ORI C_VEL

---

### 7. 精确停止（无逼近）

如果运动指令末尾**不添加任何** `C_` 关键字，机器人会精确停靠在目标点，再进行下一条运动：

krl

PTP P1    ; 精确停止在P1
PTP P2    ; 然后移动到P2，再精确停止

等价于在指令末尾加 `C_DIS` 并将 `$APO.CDIS` 设为 `0`。

---

### 8. 完整编程示例

krl

&ACCESS RVP
&REL 1
DEF APPROX_DEMO()
  ; ---- 1. 设置阈值 ----
  $APO.CDIS = 10.0      ; 距离阈值 10mm
  $APO.CORI = 5.0       ; 姿态阈值 5°
  $APO.CVEL = 30        ; 速度阈值 30%
  $APO.CPTP = 80        ; PTP阈值 80%
  ; ---- 2. 运动指令 ----
  PTP P1 C_PTP                   ; PTP逼近到P1
  LIN P2 C_DIS C_ORI             ; 距离+姿态组合逼近到P2
  CIRC P3 P4 C_DIS C_VEL         ; 圆弧运动，距离+速度组合
  PTP P5 C_PTP C_DIS             ; PTP到P5，使用PTP+距离组合（过渡到直线运动）
  ; ---- 3. 精确停止 ----
  PTP HOME                        ; 精确停靠回HOME点（无逼近）
END

---

### 9. 总结

|要点|说明|
|---|---|
|**四种模式**|`C_PTP`（PTP逼近）、`C_DIS`（距离）、`C_ORI`（姿态）、`C_VEL`（速度）|
|**PTP专用**|`C_PTP` 仅用于PTP运动|
|**CP专用**|`C_DIS`、`C_ORI`、`C_VEL` 用于LIN/CIRC运动|
|**组合规则**|允许组合使用，同时监控所有条件，执行“先到先得”|
|**格式顺序**|语法不强制，推荐 `C_DIS` → `C_ORI` → `C_VEL`|
|**精确停止**|不加任何 `C_` 关键字即精确停靠|

### 10. 扩展：相关数据结构

#### PDAT（PTP运动参数包）

krl

STRUC PDAT REAL VEL, ACC, APO_DIST, APO_MODE_T APO_MODE, REAL GEAR_JERK, INT EXAX_IGN

- `VEL`：速度（%）
    
- `ACC`：加速度（%）
    
- `APO_DIST`：逼近距离（mm）
    
- `APO_MODE`：逼近模式
    
- `GEAR_JERK`：加加速度
    
- `EXAX_IGN`：外部轴忽略掩码
    

#### 常用变量

- `PDAT_ACT`：当前激活的PTP运动参数
    
- `LDAT_ACT`：当前激活的直线运动参数
    
- `CDAT_ACT`：当前激活的圆弧运动参数
