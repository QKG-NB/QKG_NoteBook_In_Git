## 6.10 SWRITE

### 描述

SWRITE 的功能和语法与 CWRITE 类似。但与 CWRITE 不同的是，SWRITE 不将数据写入通道，而是写入一个 **CHAR 数组**。  
SWRITE 可以在程序中与 CWRITE 结合使用。优点如下：  
- CWRITE 可以仅限于将数据写入通道。更复杂的格式化任务可以由 SWRITE 执行。这使得程序更加灵活。  
- CWRITE 最多可处理 10 个变量。与多个 SWRITE 语句结合使用，可以写入超过 10 个变量的数据。  

**SWRITE 会触发预进停止。**

### 语法

SWRITE (String, State, OFFSET, Format, Var1 <, ..., Var10>)

### 语法说明

| 元素                 | 说明                                                                                                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **String**         | 类型：CHAR 数组  <br>变量 Var1 ... Var10 的格式化内容将被写入该字符串。                                                                                                                                                                                           |
| **State**          | 类型：STATE_T  <br>自动返回给 SWRITE 的状态变量  <br>（[[“State” 变量说明]]跳转链接）                                                                                                                                                                              |
| **OFFSET**         | 类型：INT  <br>SWRITE 开始写入字符串的位置。如果要从开头开始写入，偏移量必须设为 0。  <br>**示例：**  <br>- OFFSET=0：SWRITE 从第一个位置开始写入。  <br>- OFFSET=2：SWRITE 从第三个位置开始写入。忽略第 1 和第 2 个位置。  <br>写入过程中偏移量会递增。如果在另一个 SWRITE 语句中要从第一个位置重新开始写入，则必须在该语句之前将偏移量设为 0。否则，将沿用前一个语句递增后的偏移量。 |
| **Format**         | 类型：CHAR 数组  <br>在变量 Var1 ... Var10 写入字符串之前对其进行转换。每个变量都必须指定一个格式。  <br>（参见 6.15 节 “Format” 变量，第 33 页）                                                                                                                                         |
| **Var1 ... Var10** | 数据被写入字符串的变量。每条语句最多支持 10 个变量。                                                                                                                                                                                                                |
